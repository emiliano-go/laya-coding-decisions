## Conclusion

**FAIL.** Laya scores 0.224 macro-F1 in both settings. The cheap baselines score
0.439 (TF-IDF) and 0.446 (potion embeddings) in-project, and 0.484 / 0.500
cross-project. The bar was "best baseline + 0.10, at least 0.55", so the gap is
-0.222 against the embedding kNN — not close.

Worse than the bar: Laya's accuracy (0.549) is *below* the global majority
(0.686). It never predicts `decision` or `contract` at all, catches 2% of
`gotcha`, and is right on `implementation` only because that class dominates.
The bootstrap CI on `laya - tfidf` (10k, project-clustered) is
[-0.279, +0.065]: the point estimate is negative and the interval excludes any
useful gain.

This closes Task 1. The answer to "can Laya type memories" is no; the answer to
"what should type memories" is the embedding kNN (0.446) or plain TF-IDF
(0.439), which are both free and already available.
